## 📊 QUÉ INCLUYE TERMINAL BATTLE

### Especificaciones Técnicas:
```
✅ 32 ejercicios progresivos de Debian/Linux
✅ Mecánica de videojuego RPG (VOX vs Boss)
✅ Sistema de combate: respuestas directas = daño
✅ Barras de vida visual para player y boss
✅ Sistema de monedas + tienda de items
✅ 4 items comprarables (Poción, Espada, Escudo, Bomba)
✅ Sistema de pistas (-5 vida)
✅ Opción saltar (+10 vida)
✅ 3 paneles: Personajes, Terminal, Inventario
✅ Efectos visuales (animaciones, popups, glows)
✅ Pantalla de victoria/derrota
✅ Estadísticas en tiempo real
✅ 32 comandos diferentes para aprender
✅ Tema: Dark mode estilo hackers/cyberpunk
```

### Temas Educativos Cubiertos:
```
📁 Directorios
   - mkdir / cd / pwd / ls / cd .. / cd ~

🔐 Permisos  
   - chmod (simbólico: u+r, g+w, o+x)
   - chmod (octal: 755, 644, etc)
   - chown / chgrp
   - Niveles: usuario, grupo, otros

📄 Archivos
   - touch / cp / rm / mv / cat / stat
   - cp -r / rmdir
   - ln -s (enlaces)

🔍 Búsquedas
   - find / grep
   - Parámetros: -name, -l, -a, -h, -R

⚙️ Avanzado
   - Permisos recursivos
   - Directorios anidados
   - Formatos de lectura legible (-h)
```

## 💡 TIPS Y TRUCOS

### Para Pasar el Juego:
```
1. No saltes los primeros 10 ejercicios (aprende bien)
2. Recoge monedas en los ejercicios del medio
3. Compra Escudo de Conocimiento (20 monedas) midway
4. En fin juego, compra Bomba de Código (50 monedas)
5. Lee pistas si no sabes (cuesta -5 vida)
Status optimal: 10 monedas, 50 HP en ejercicio 25
```

### Para Entender Linux de Verdad:
```
Paso 1: Termina el juego
Paso 2: Abre terminal de verdad (linux/mac) o WSL (Windows)
Paso 3: Ejecuta estos comandos:
  mkdir aprender_linux
  cd aprender_linux
  touch archivo.txt
  chmod 755 archivo.txt
  ls -l
Paso 4: Entiende que el juego es EXACTO a la realidad
```
